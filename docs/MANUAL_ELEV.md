# Elevmanual

Den här manualen visar hur du använder appen.

## 1. Logga in

1. Öppna klasslänken eller QR-koden som läraren har delat.
2. Kontrollera att rätt klassnamn visas under `Du loggar in i klass`.
3. Skriv ditt namn så som läraren har lagt in det.
4. Skriv din personliga fyrsiffriga kod och klicka `Logga in`.

Du väljer inte skola eller klass själv. De är redan kopplade till länken och lärarens klasslista. Kryssa bara i **Kom ihåg mig på den här enheten** på din egen enhet. Då kan inloggningen sparas i upp till 30 dagar; annars gäller den i upp till 12 timmar.

Har du glömt koden eller får felmeddelande flera gånger, be läraren om hjälp. Läraren kan ge dig en ny kod.

## 2. Startsidan

På elevens startsida finns normalt:
- knapp för att starta pass (uppdrag/fri träning),
- tabellövning (2–12),
- val av räknesätt,
- sektionen `Framsteg`,
- eventuellt `Aktiv ticket`.

## 3. Välj träning

Elev kan starta:
1. Fri träning.
2. Ett specifikt räknesätt.
3. Tabellövning (val av tabeller).
4. Nivåfokus via `Framsteg` (klicka en nivå-ruta).

## 4. Under en uppgift

- Uppgift visas med stor text.
- Inmatning kan göras med tangentbord eller knappsats på skärmen.
- Rityta kan visas/döljas under uppgiften.

Knappar:
- `Svara` när eleven svarar på uppgift.
- `Nästa` efter feedback.
- `Radera` tar bort sista tecknet.
- `Rensa` tömmer hela svaret.

## 5. Feedback

- Vid rätt svar visas korrekt feedback och appen kan gå vidare automatiskt.
- Vid fel svar visas `Du svarade ...` i rött och eleven går vidare när hen är redo.

## 6. Pausförslag

Appen kan föreslå kort paus efter en mängd uppgifter. Eleven kan fortsätta direkt. Om eleven vill spela en snabb pausaktivitet finns:
- `Pong` (max 2 minuter),
- `Snake` (max 2 minuter).

## 7. Ticket

Om läraren skickat ticket kan eleven se den:
1. via direktlänk,
2. eller tydligt på startsidan som `Aktiv ticket`.

Eleven svarar i ticketvyn och kan beroende på lärarens inställning:
- se rätt/fel direkt,
- eller få facit/rättning senare.

## 8. Framsteg

I `Framsteg` ser eleven nivå-rutor per räknesätt.

- Grön: klarad nivå.
- Blå: påbörjad.
- Grå: ej startad.

Elev kan klicka nivå-ruta för att träna just den nivån.

## 9. Tillbaka till startsidan

Eleven kan alltid gå tillbaka till sin startsida via knappen `Startsida` utan att logga ut och in igen.
